# Cada página, un mundo

Reflexión personal sobre el texto de Chia Amisola, hecha como un pequeño sitio web con HTML y CSS.

Es una modificación (fork) de la plantilla **agua-0** de [Juliansintilde](https://github.com/Juliansintilde/agua-0), basada en un tutorial de [@jaimander](https://github.com/jaimander).

## Qué hay en este proyecto

- `index.html`: portada del sitio, con el título que lleva a la reflexión.
- `pagina-2.html`: mis apuntes y reflexión sobre el texto de Chia Amisola.
- `style.css`: estilos de la página (colores y tipografías Playfair Display y Lora).
- `elementos/`: imágenes e íconos que usa el sitio.
- `script.js`: archivo de JavaScript de la plantilla, sin uso en este proyecto.
